# Can I use this on a server that does not have the mod?

Yes. Join as usual and you keep almost everything: Build and Edit mode, rotation, nudging,
snapping, the build camera, longer reach, area repair and building from chests. Nobody
else needs the mod, and the pieces you place are ordinary pieces to everyone else.

A few things stay off there:

- **Stronger Pieces** and **Repair Upgrades.** Players without the mod would undo them,
  and on a large build that could make pieces collapse for no visible reason.
- **Building rules** under `7. Building Rules` stay vanilla, whatever your own settings
  say. Only a server running the mod can change them.

The console commands `valchitecture stats` and `valchitecture world` tell you when
these are off.

If a server does run the mod, every player needs it too, and all of these then work for
everyone on it.
